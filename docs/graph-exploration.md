# 交互关系图与最短有向路径

更新日期：2026-10-26。P2-2 第三阶段已实现 Core 图索引、Qt 交互画布和 CLI/Qt 最短路径。当前为本地 Windows 验收；本阶段尚未推送或运行新的独立远端 CI，P2-2 整体仍保留验收缺口。

## 使用

载入含 Clang 分析的快照，在“关系图”页选择调用图或包含图。也可以在“符号”或“度量”表中选中函数，右键“在调用图中查看此函数”。

- 检索函数名、文件名或符号 ID，最多显示 100 个匹配项并显示总数；当前按原始 UTF-8 字符串作区分大小写的子串匹配。
- 双击检索结果展开邻域；右键可将所选节点设为路径起点或终点。同名重载保留各自身份，输入同名文本有歧义时要求选择确切节点。
- 邻域支持出向、入向、双向，默认出向深度 2、60 个节点；深度可选 0—8、节点上限可选 10—200，关系边最多绘制 600 条。深度范围、显示数量和达到上限的情况均显示在状态文字中。邻域之外的节点没有被证明不存在。
- 拖动节点时箭头随之更新；拖动空白平移，滚轮或按钮缩放，“适应”重新居中。自环用曲线表示。窄窗口通过滚动访问完整控件及结果，不强行压缩画布与路径列表。
- 选择两个端点后点击“最短有向路径”。路径只沿保存的边方向查找，与邻域当前选择的入向/双向模式无关。起终点相同时得到零边路径，不把它当作自环检测。
- 路径表按需读取完整结果；画布最多显示路径前 200 个节点，并明确提示截断。双击节点跳到定义/声明，双击路径边跳到该关系的首个保存位置，保留 UTF-8 字节列。

路径端点也可直接输入唯一名称或确切 ID。ID 来自当前快照的符号/关系数据，不可假设同名函数、旧分析器版本或不同 TU 的内部链接实体共用 ID。

CLI 沿用 `graph` 命令，增加成对的 `--from` / `--to`：

```powershell
$cli = '.\build\codeguard-analysis\codeguard-cli.exe'
& $cli symbols $project --database $db --prefix alpha
& $cli graph $project --database $db --kind call --from $sourceUsr --to $targetUsr
& $cli graph $project --database $db --kind include --from 'main.cpp' --to 'api.h'
```

使用实际查询到的端点替换示例变量；包含图端点按保存的文件标识精确匹配，外部文件可能保存绝对路径。输出 `path_found`、`path_edges`、访问节点数、节点身份及逐边行列/位置数；不存在路径时 `path_found=0`，不报成程序安全。部分解析保留 `analysis=partial` 和退出码 2。未分析/分析失败的快照不能提供新图索引；未知端点、缺少配对参数会报错。CLI 路径构造与搜索支持 Ctrl+C 取消。

## 数据与边界

调用图使用已保存的函数符号和静态调用边；包含图使用文件清单和 include 边。孤立节点保留，端点中出现的外部节点也保留。未知调用端点不编造源码位置。相同起终点合成一条画布关系，`location_count` 统计不同的文件/行/列位置，首个位置按字典序稳定选择；它不是 TU 数、调用次数或运行时频次。

最短路径由完整保存图上的迭代 BFS 求得，相同长度按稳定节点 ID 顺序选取。图中含环、递归和自环时仍可终止；三万边深链不依赖递归栈。路径存在只说明保存的静态关系可连接，不说明该运行路径可执行、参数满足约束或缺陷必然发生。没有路径也不能证明运行时不可达，尤其在部分解析、间接调用、虚分派和缺少编译配置时。

索引、检索、邻域提取和路径搜索在后台执行，保留取消和请求版本。切换快照/图类型或发出新请求会丢弃过期结果；取消不写数据库。画布节点/关系数量有界，长路径用表模型显示。仍需在内存中持有完整扫描快照和图索引，未实现数据库端的流式图查询。

图由现有 schema 7 快照关系派生，没有新数据库迁移，也不改变已有分析器/规则算法。源码跳转复用工程清单、路径边界、文件大小和内容变化检查；外部节点不会绕过工程范围读取文件。历史快照仍可查看保存的关系，源码不存在或已改变时不能据旧行列断言当前代码位置准确。

## 本轮验证

Windows 完整回归：Core 61 项中 60 通过、1 跳过；Clang/Qt 120 项中 119 通过、1 跳过。跳过项均为符号链接权限测试，不计为通过。完整回归后调整了关系图窄窗口的滚动布局，相关 14 项及新增紧凑布局断言单独复测通过；CLI 空端点拒绝行为另经导航合同测试复测，最终运行包也重新检查。图专项包含五组 Core、三组 Qt 合同测试，并由既有主窗口 smoke 通过实际 QAction、后台任务、路径表和源码定位验证集成。

专项覆盖稳定去重/证据位置、调用与包含图、重载身份、出入方向、深度与上限、环/自环/断连/零边路径、未知端点、取消、过期快照、图类型切换、取消后重建，以及三万边路径的完整尾部数据和有界画布。三万行路径的界面心跳在本轮完整回归中最大间隔为 19 ms；这是本机受控样例结果，不保证所有机器或工程性能。
