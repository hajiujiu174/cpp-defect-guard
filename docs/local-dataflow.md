## 分析范围

CG005 在原空常量检查上增加函数内标量指针传播；CG002 在原编译期常量下标检查上增加局部整数区间传播。每个函数独立分析，不推断函数调用的参数/返回值、不追踪堆对象或复杂别名，不执行源码。两项沿用既有启停、级别、带理由抑制、CLI/Qt 问题定位和报告接口。

支持局部初始化、直接赋值、指针复制、整数加减乘及增减、if/else、提前 return、条件运算符和内置短路与/或。指针状态为未知、空、非空；整数使用闭区间，当前传播范围限定为不超过 32 位的非枚举整数。比较条件可收紧同一类型整数的上下界，分支合并取区间并集的包络；只有所有合并路径均为空，指针合并结果才为空。

```cpp
int null_case() {
    int* p = nullptr;
    int* q = p;
    return *q;                 // CG005：局部传播得到空指针
}
int range_case(bool choose) {
    int a[3];
    int i = choose ? 3 : 5;
    return a[i];               // CG002：整个区间 [3,5] 越界
}
int unknown_case(bool choose) {
    int a[3];
    int i = choose ? 2 : 5;
    return a[i];               // 区间含合法值与越界值，本阶段不作确定告警
}
```

CG005 检查解引用及箭头访问；CG002 仍仅针对已知定长数组，不把指针大小当数组长度。`&a[size]` 的尾后地址保留合法，`&a[size+1]` 可以报警；`&*p` 不当作实际解引用。问题消息区分常量检查和 `Local` 传播，区间问题记录推得上下界。普通条件中的结论是“到达该语句且满足已分析约束时”的状态，不证明整条运行路径必然可达，也不证明存在某个实际调用输入。

## 未知与保守退化

- 取变量本身地址、建立引用别名、按引用捕获、传入引用参数的变量，在整个函数内不参与传播。记录类型初始化可能绑定引用成员并在析构时修改标量，因此其中使用的变量也保守排除。取数组元素地址不会把下标变量误当成逃逸变量。
- 未建模调用、构造、用户转换和复杂表达式会丢弃相关状态；未知求值顺序的兄弟表达式从保守状态独立分析，不能把某个顺序的赋值当成既定事实。
- volatile、静态局部/全局存储、超过 32 位整数、枚举、指针运算、动态分配数组范围及跨过程传播暂不支持。可能溢出、回绕或窄化的运算回到目标类型的未知范围。
- 未实例化模板的圆括号初始化可能保留没有类型的 `ParenListExpr`；跳过其求值并清空已有状态，不把语法占位节点当成已知值。模板实际实例化后仍按其实际 AST 独立分析。
- 循环先检查已知不可能进入的情况，再把循环可能写入的变量放宽为未知，依赖显式循环条件分析循环体；离开循环不保留未经证明的归纳变量值。不推断迭代次数、终止性或完整 break 路径。
- switch、异常处理和未支持的控制结构不执行局部传播；其后状态清空。有 goto、标签、内联汇编或协程控制的函数整体跳过局部传播。独立的既有 AST 规则仍会运行。
- 跳过 sizeof、noexcept 和当前不建模的 typeid；lambda 体不归外层函数。局部分析设有函数级 100,000 步预算，耗尽后不产生新的传播结论。

未知通过保守状态参与合并，不能当作非空、下标安全或“规则验证通过”。没有告警仍不代表无缺陷；`analysis=complete` 一直仅描述 TU 解析完成，不代表这些路径均被证明安全。
