# 第二层可靠性与稳定性验收

## 范围与实现

v0.5.0（2026-09-07）继续完善第二层，不实现第三层自动修复，不修改原课程设计 DOCX。模型架构、训练损失、固定数据划分和旧检查点均保留。

- 数据入口：严格验证 JSON 对象、重复字段、非有限数、源码哈希、节点/边类型、显式边与索引的一致性。外部标签不得继承图中的监督标签；原始来源组必须保留，再次划分时保留去重追溯关系。划分清单的样例、组、类别计数须与实际数据一致。
- 模型加载：检查模式、维度、词表、阈值、权重哈希、张量名称/形状/类型/有限性。编码器主干缺失或不匹配不能用随机初始化权重继续；只允许预训练语言模型头的预期额外权重。
- 编码缓存：新缓存保存身份及内容指纹，检查有限的 768 维 float32 向量，临时文件完成后原子替换；损坏即报错。旧缓存仅做形状/类型/有限性检查，明确标记 `legacy-shape-checked`，不能追溯证明原内容未被改写；本轮实验使用独立的新缓存目录。
- 覆盖诊断：扫描列出未覆盖的文件、缺少 AST 的函数，以及序列截断的函数、原始 token 数和保留数量。模型概率为 NaN/Inf 时拒绝生成报告，不把它当作无告警。
- 多种子实验：预登记数据/划分/编码器指纹、模式、种子和超参数。保留全部运行及错误状态；按验证集选轮次，不按测试结果选种子。恢复前核对计划和检查点，并从预测重算指标。

## 环境预检

在项目根目录使用模型环境执行：

```powershell
$env:PYTHONPATH = "$PWD\src"
.\.venv-ml\Scripts\python.exe -m defectguard doctor .\samples\ml_corpus `
  --config .\artifacts\layer2\demo-20260906\scan-model.toml --json
```

`model_preflight` 检查当前解释器下的依赖版本、检查点基本元数据、编码器文件、原生工具和编译数据库。保留原有环境诊断字段；新增 `layer2` 状态。已启用模型但条件不足时，文本和 JSON 模式都返回退出码 2。严格 Clang 配置也不能仅凭词法后端可用返回成功。

预检不导入深度学习框架、不读取完整权重、不实际执行原生分析器或推理。`preflight-passed` 仅表示这些轻量条件通过，仍须以实际扫描验收。基础 Python 缺少 ML 包时不自动安装，也不影响默认禁用模型的规则扫描。

## 多种子运行与恢复

本机已有数据集时：

```powershell
.\scripts\run_model_stability.ps1 -RunTests
```

新机器先按 [模型实验说明](layer2-experiments.md) 准备环境和数据，再用 `-Dataset` 指定已完成独立标注及划分的数据集。脚本默认复用 `artifacts/layer2/demo-20260906/dataset`，不会隐式重划分，也不下载权重。

默认三种模式、种子 42/43/44、40 轮、最大序列长度 256、隐藏维度 48、学习率 0.003、阈值 0.5。数据划分种子保持 42。可以指定 `-Seeds 11,12,13` 和 `-Epochs`，但这些配置必须在首次训练前确定。

恢复已有计划：

```powershell
.\scripts\run_model_stability.ps1 `
  -OutputDirectory .\artifacts\layer2\stability-20260907 -Resume -RunTests
```

恢复时须提供相同参数；完整检查点校验通过后标记 `reused=true`，只训练尚不存在或空目录的运行。若已有非空但不完整/损坏的检查点则停止并保留，不自动覆盖。完成后也可恢复来核对全部结果。不要让多个进程同时写同一输出目录。

```text
artifacts/layer2/stability-时间戳/
├─ plan.json                 训练前登记的固定配置与输入指纹
├─ progress.json             每次运行的状态、错误及是否复用
├─ sequence-seed42/          每种模式/种子独立的检查点、历史与预测
├─ ...                      默认共 9 个模型目录

```

## 本机实际结果

2026-09-07 完成全部 9 次训练。固定测试集为 10 个函数（5 正例、5 负例）、2 个来源组；训练 12、验证 2。表内为三个初始化种子的均值 ± 样本标准差。

| 模型 | Precision | Recall | F1 | Accuracy | Top-1 | 端到端 Top-1 |
|---|---:|---:|---:|---:|---:|---:|
| sequence | 0.400 ± 0.346 | 0.400 ± 0.346 | 0.400 ± 0.346 | 0.567 ± 0.058 | 不支持 | 不支持 |
| gnn | 0.524 ± 0.041 | 0.667 ± 0.231 | 0.575 ± 0.116 | 0.533 ± 0.058 | 0.600 ± 0.000 | 0.533 ± 0.115 |
| fusion | 0.567 ± 0.058 | 0.600 ± 0.000 | 0.582 ± 0.031 | 0.567 ± 0.058 | 0.600 ± 0.000 | 0.600 ± 0.000 |

序列基线在种子 44 下全预测为负例，测试 F1 为 0，说明单次结果不足以描述稳定性。不能因此按测试集挑选其他种子发布为最佳模型。融合与 GNN 的均值接近，当前数据不足以作优越性或显著性判断。

标准差衡量固定测试集上的初始化敏感性，不是标准误或置信区间。三次预测不会把 10 个函数变成 30 个独立样本；当前来源组太少，尚未提供可靠的泛化区间估计。全部指标和逐样例复核见 `artifacts/layer2/stability-20260907/summary.md` 与 `cases.json`。
