# 验证输入投影与快照内存

更新日期：2026-10-27。第十阶段为提案、源码副本构建、单项/批量/组合验证及多轮覆盖对照增加独立的验证输入读取。它保留验证门槛所需元数据，省去这些入口不用的完整图数据。完整验收见 [机器可读证据](evidence/validation-inputs-20261027.json)。

## 接口与数据范围

`SqliteDatabase::validation_inputs(root)` 返回独立的 `ValidationInputs` / `ValidationAnalysis`，包含扫描 ID、根目录、时间、变化计数、文件全部字段、清单范围策略、分析状态、配置、分析器版本、编译数据库、每个编译单元的状态/诊断/命令指纹/覆盖文件、整体覆盖、活动/抑制问题和规则诊断。`latest_scan_id(root)` 只查当前扫描 ID，用于比较结束时的过期检查。

该类型没有符号、引用、函数度量、关系边或构建历史字段，也不能隐式转换成 `ScanResult` / `AnalysisResult`。编译期检查拒绝把它当作完整快照保存；查询和报告仍要求完整快照。`latest()` 和历史 `snapshot()` 继续读取完整数据，使用同一份元数据读取逻辑，数据库格式维持 schema 7。旧库、未知项目、源目录已移走及取消保持各自语义。

`validation_inputs_of(full)` 是显式的单向投影。已有完整快照提案 API 保留，内部委托给同一验证输入流程；新 API、CLI 与公共多问题提案工具可直接使用轻量输入。GUI 仍需要完整快照服务符号、查询和图导航，本阶段减少的是验证时的额外读取和副本，不承诺主界面或 AST 分析只占用这些内存。

## 原有门槛

提案仍从当前源码重新解析全部既定编译单元，检查文件清单、活动问题、编译指纹和解析范围；不复用历史修复提示。验证仍保留原始/拟议完整 C/C++ 清单与内容检查、精确编辑、全副本构建和 CTest、同配置原始对照、修改后完整静态分析及各覆盖率门槛。投影不会减少文件或 TU，也不把问题消失或测试通过等同于修复正确。

输入类型保留的分析状态表示已保存扫描的状态，不表示它包含完整图。轻量读取结果不进入完整快照的保存、查询或报告接口；内部读取范围选择不作为公共的“空图完整快照”选项暴露。

## 测量方法与范围

只读探针在同一份 libgit2 数据库上交替读取完整快照和验证输入，文件数 599、物理行数 271818、C/C++ TU 数 244、活动问题数 23。独立字段格式逐字节比较全部保留数据，包括每个文件的语言/摘要/大小/时间/行数、命令指纹、每 TU 覆盖、抑制理由和配置；读取前后检查数据库 SHA-256 不变。

峰值来自 Windows 进程计数器，两种读取使用同一探针二进制、相同元数据序列化和相同 200 ms 读后停留，确保轻量进程结束前采样到 OS 峰值。进程墙钟包含启动、序列化及该停留；探针输出的读取秒数排除序列化和停留。串行两轮是本机观察，不作为固定系统负载或所有工程的通用基准。

初步实际结果：完整读取工作集 337.22 / 336.74 MiB，验证输入 11.07 / 11.06 MiB；保留字段完全一致。此数字仅属于输入读取进程；原有完整快照、现场 AST 和主界面图仍可能占用较多内存。

最终本机回归：Core 105 项中 104 通过、1 权限跳过；Clang/Qt 236 项中 235 通过、1 权限跳过。10 项专项均通过，真实库 a4 的两组合原版/修改版各 244 TU 全部解析；修复组合四项通过，意图负对照三项失败，23→19 无新增/显现问题、原始和拟议内容核对及三个参考函数结构关系保持。完整扫描和提案复用单列，不称为重新生成。

## 验收与记录

单元检查通过 SQLite 授权回调，禁止读取符号、引用、函数度量、图和构建历史表，验证轻量读取与 ID 检查成功、完整读取确实被拒绝；另确认恢复授权后完整图仍可读取。还覆盖字段对照、过期 ID、旧格式、未知/已归档源码、开始前和读取中取消、在禁止读图时实际构建，以及完整/轻量 API 提案字节一致性。

首轮旧格式样本因缺少 CodeGuard `application_id` 被原校验拒绝；仅修正合成样本标识，再在新目录复测，未放松生产格式校验。失败日志、修正后记录和独立运行包结果分别保留于 `artifacts/p3-validation-inputs-20261027/`。

最终 Core/Clang/Qt 回归和真实库验证范围以机器证据为准。完整编译现场与数据库留在本机，程序包提供更新后的 Core SDK。没有训练新模型、自动应用补丁到用户工程、提交、推送或独立远端 CI；正确性仍为 `not_assessed`。
