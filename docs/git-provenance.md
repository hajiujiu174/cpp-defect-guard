## 当前行为

只有所选源码根目录具有自己的 `.git` 目录或文件，才采集 Git 记录。普通子目录、提取的归档及无 Git 元数据目录的提交号保留未知；不继续读取父仓库的分支、状态或差异。主动导入现有仓库的子目录也采用这个规则，不能把父仓库 HEAD 自动当作子目录独立版本。

每次读取先清空调用方旧的提交号，显式绑定 `--git-dir` 和 `--work-tree`，并核对 Git 返回的工作树根。该绑定覆盖继承的 `GIT_DIR` / `GIT_WORK_TREE`；没有提供对全部 Git 配置、环境变量或外部对象库的隔离。正常仓库、嵌套独立仓库、链接工作树和子模块仍使用各自本地元数据。根或提交号探测失败、取消、输出截断、路径非法，或提交号不是完整的 40/64 位十六进制值时，不确认提交号。HEAD 已确认后发生其他 Git 命令失败时，保留该 HEAD 及逐项失败日志，不把整段采集当作原子快照。

Git 仍使用独立参数、禁用可选锁与 fsmonitor，差异关闭外部 diff 和 textconv，保留超时、取消和输出上限。Git 元数据未知不会单独阻止普通源码副本构建；新构建记录在 SQLite 中保存空提交号和明确原因，已有报告中的提交号显示为“未知”。数据库格式和历史记录没有重写。
