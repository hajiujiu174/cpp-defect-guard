# 五类规则固定评测集

本目录为项目内编写的 45 个 C++20 合成样例，每条规则 9 个独立翻译单元。只供 Clang 解析，包含有意构造的未定义行为，测试不会链接或运行这些函数。它们用于规则行为回归，不是来自真实工程的随机抽样。

`manifest.tsv` 的 `rule` 与 `case` 组成文件名；`label` 是人工标注的目标风险/语法模式，`expected_findings` 是当前检测能力的回归基线，两者含义不同。`positive` 且基线为 0 是明确保留的已知漏报，不能改成负例来提高统计结果。CG001 标注的是无容量参数的库 API 调用风险，并不证明目标缓冲区发生溢出。

每个文件只包含一个目标位置。评测先要求所有 TU 成功解析，再对该规则按文件、行、列去重：正例有命中计 TP、未命中计 FN，反例有命中计 FP、未命中计 TN。不同模板实例可能保存多个函数标识下的 Issue，本评测将同一源码位置算一次；统计也不评价其他位置的定位偏差。解析失败会使测试失败，不会计入 TN 或当作无缺陷。

| 规则 | 正例与扩展场景 | 不应报告的反例 | 已知漏报 |
|---|---|---|---|
| CG001 | 直接库调用、宏、模板 | 同名用户函数/成员、有界调用、sizeof、丢弃的 constexpr 分支 | 间接函数指针调用 |
| CG002 | 正/负常量越界、宏、模板 | 合法下标、尾后地址、sizeof、模板合法分支 | 参数传递后的动态下标 |
| CG003 | if/while 条件赋值、宏、模板 | 显式括号、比较、for 步进、有意赋值宏、括号赋值与逻辑条件组合 | 本集合未标注能力范围外正例 |
| CG004 | 局部变量/数组地址返回、宏、模板 | static、引用、调用方指针、堆对象 | 通过局部指针别名返回 |
| CG005 | 空常量解引用/箭头、宏、模板、lambda | 有效指针、非求值上下文、地址与解引用抵消 | 空指针变量的值传播 |

CG003 的 `(x = 1) && y` 已通过括号明确意图，标为反例，与直接未加括号的条件赋值区分。当前集不提供所有规则的全域缺陷真值，不能据此推断真实项目 Precision、Recall 或 F1。

构建 Analysis 版后在仓库根运行：

```powershell
ctest --test-dir build/codeguard-analysis -L rule_evaluation -V
```

CTest 分别运行 `codeguard.evaluate_CG001` 至 `codeguard.evaluate_CG005`，每次仅启用相应规则，生成独立编译数据库；日志打印每个样例的标签、命中位置数及 `RULE_EVALUATION` JSON。基线变化使测试失败，需先检查代码、位置与标注理由再更新。完整设计及验收见 [规则引擎](../../docs/rule-engine.md)。
