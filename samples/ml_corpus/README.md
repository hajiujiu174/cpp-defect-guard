# 第二层受控演示数据

24 个自建函数（12 对缺陷/修正版本），只用于验证数据—训练—评估—扫描流程，不是公开基准，也不能据此推断真实工程精度。

标签在 labels.jsonl 独立维护；rule_findings 不参与标签生成或默认模型特征。函数名统一为 process，a/b 版本交错安排。group_id 把同一修复对以及相近的数组边界、堆生命周期变体放入同组，共 7 个来源/模板组。划分时整组移动，不把成对版本拆散。分组仍无法保证不同组间没有语义相似性。

正例覆盖常量越界、空指针、未初始化、内存泄漏、重复释放、释放后使用、除零、文件泄漏和字符串溢出；每个正例标注一个主要缺陷行。负例表示对应受控缺陷已消除，并非通用安全证明。标签为本项目自建并经代码逻辑核对，未经第三方独立专家审定。

CMake 仅编译 OBJECT 目标，不链接或运行这些含未定义行为的正例。构建成功仅说明样例语法可分析。原始样例与 labels.jsonl 均是输入材料；图数据、数据划分、权重和指标写入 artifacts 下的独立目录。
